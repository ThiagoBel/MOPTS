# MOPTS – Menu de Opções para Console (Windows)

**MOPTS** é uma biblioteca simples e Header-Only de C++ para criar menus interativos no console do Windows.

> ⚠️ **APENAS WINDOWS** (pois usa `windows.h` e `conio.h`)

---

### Funcionalidades

- Navegação com:
  - Setas do teclado
  - `W` / `S`
- Seleção com:
  - `Enter`
  - `Espaço`
- Execução de funções ao selecionar uma opção

---

### Requisitos

- Windows
- Compilador C++ compatível com:
  - `<windows.h>`
  - `<conio.h>`
- C++98 ou mais

---

### Instalação

1. Copie o arquivo `MOPTS.h` para o seu projeto
2. Inclua no seu código:

```cpp
#include "MOPTS.h"
```
